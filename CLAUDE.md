# CLAUDE.md

Guidance for Claude (and any AI assistant) working in this repository.

## Architecture Decision Records (ADRs)

Read every ADR in `docs/adr` before making changes, and write a new ADR for every
big decision.

- ADRs live in `docs/adr`, one numbered file per decision (e.g.
  `0001-use-nextjs-with-material-ui.md`).
- Use `docs/adr/TEMPLATE.md` as the format for a new ADR.
- When a decision changes, do not erase the old ADR — write a new one and set the
  old ADR's status to "Replaced by ADR-0000" (the new number).
