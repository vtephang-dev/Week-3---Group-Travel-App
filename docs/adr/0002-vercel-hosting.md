# ADR 2: Host the app on Vercel

**Status:** Accepted
**Date:** 2026-11-12

## Context
I needed Vercel to be able to publish the app on the internet, which would
allow real users to visit the app. It is also free.

## Decision
I chose to use Vercel to host my live app.

## Consequences
I gain free hosting that real users can visit on the internet. The downside is
that the free plan has limits, such as usage caps and Supabase pausing inactive
projects.
